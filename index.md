# Twotter Revived

Twotter Revived is a free, community-created "total overhaul" mod for
Aerosoft's Twin Otter for MSFS (2020).  Our custom code is open-source
and only restricted by licenses of bundled components.

The goals of the project have changed over time. It started as an
attempt to fix some of the issues the _Aerosoft Twin Otter (MSFS)_
started showing in MSFS 2024.

Then the goal became restoring the glory of the _Aerosoft Twin Otter X
Extended_ for FSX/P3D, the best rendition of the Twotter in the
Microsoft Flight Simulator ecosystem.

Currently, the goal is to attempt a faithful recreation of this
legendary aircraft, leveraging the latest systems in MSFS 2024 and
replacing stock sim systems with custom code wherever sim restrictions
would hinder us from achieving the stated goal.

## Scope

I cannot modify the 3D model of the actual aircraft in any meaningful
way. Everything else is on the table.
