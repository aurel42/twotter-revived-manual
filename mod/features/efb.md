# The "Twotter" EFB app

## Overview

The EFB app is an integral part of the mod, unlocking many of its
features. I recommend you make yourself familiar with it when you
first start the mod.

The app can be started from the "More Apps" tab of the EFB (bottom row
of the EFB, rightmost icon).

Recommended first step in the app: check out the 
[Config tab](../configuration.md), 
pick a profile that fits your expectations and adjust the options from
there.

## Disclosure modes

Note the toggle at the top, between the notification icon and the
timestamp. It displays the mode the app is currently in:

- "Limited" tries to limit the information presented on some of the
  tabs to what would be available to the pilot in flight. It also
  hides some tabs completely, e.g. the Radio and TAWS tabs.

- "Instructional" lifts this restraint and offers insights that might
  help you understand system internals as they happen.

Click it any time to switch between modes. If you're a roleplayer,
consider it the "cheat button".

> [!WARNING]
> Information presented in the EFB app that appears to reference

	real-world data or information is FOR SIMULATION USE ONLY.
	The Checklists and Reference tabs explicitly say so.

## Notes

- This manual is available on the Manual tab of the EFB app.

- If the WASM module or panel configuration fails to load, the EFB
  shows a splash saying so, with a "continue anyway" option, plus an
  SOS blink on the hydraulic-pressure warning lamp. Note that the
  aircraft is not airworthy if the basic components fail to load.

- **Systems:** The Anchor button (float and amphibian variants)
  freezes the aircraft in place on the water. It's a hack and
  placeholder for a better anchor or mooring system down the line.

- **Systems:** The Headset toggle muffles engine and gyros sound ONLY
  when the companion sound mod is in use.

- **Payload:** The load manager has a "Redist fuel" button
  specifically for FSEconomy users. You can also move the fuel slider
  back and forth to balance the fuel. To set fuel in individual tanks,
  use the standard Weight & Balance app.

- **Payload:** The default passenger weight is configurable on the
  Config tab to a fixed or random weight.

- **Instruments, Ice:** Some tabs are work in progress. Who am I
  kidding?  Everything is constantly work in progress!

- **Reference, Manual:** The navigation bar on the left can be hidded
  to reveal more of the content.

- **Reference:** The Performance sections contain some experimental
  renderings of Live Performance Charts that try to help you decipher
  performance charts.

- **Maint:** The Maintenance tab is only available when the
  Reliability slider on the Config tab is not in the "Off" position
  and the session has been restored. It is hidden in "Limited" mode if
  an engine is running.
